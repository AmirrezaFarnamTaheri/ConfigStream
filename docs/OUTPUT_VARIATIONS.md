# Output Variations Reference

This document lists ALL output file variations generated by ConfigStream, ensuring comprehensive coverage of all technologies, evasions, and revival modes while maintaining backward compatibility.

## Output Categories

### 1. Standard Outputs (Legacy - Always Generated)

These are the core outputs that have existed since the beginning. They are **never removed** for backward compatibility.

#### Primary Formats
- `singbox.json` - Standard Sing-box config (Sniper profile)
- `singbox-vpn.json` - Sing-box TUN/VPN profile (Tank profile)
- `clash.yaml` - Standard Clash config
- `base64.txt` - Universal base64 subscription
- `proxies.txt` - Plaintext URI list
- `proxies.json` - Full dataset with metadata

#### Adapter Formats
- `shadowrocket.txt` - Shadowrocket format
- `surge.conf` - Surge format
- `loon.conf` - Loon format
- `quantumult.conf` - Quantumult X format
- `sip008.json` - SIP008 format

#### Specialized Outputs
- `chosen/base64.txt` - Top proxies per protocol
- `singbox-chains.json` - All chains (washed + revived + smart + shielded)
- `chains.json` - Alias for singbox-chains.json
- `revived.json` - Revived proxies only
- `side_products.zip` - OpenVPN + WireGuard configs

#### Categorized Outputs
- `countries/{CC}.json` - Proxies by country code
- `protocols/{protocol}.json` - Proxies by protocol

### 2. DNS-Safe Outputs (IP-Only)

All standard outputs have DNS-safe variants with `-dns-safe` suffix. These use pre-resolved IP addresses to bypass DNS poisoning.

#### Primary Formats
- `singbox-dns-safe.json` - IP-only Sing-box config
- `singbox-vpn-dns-safe.json` - IP-only Sing-box VPN config
- `clash-dns-safe.yaml` - IP-only Clash config
- `base64-dns-safe.txt` - IP-only subscription
- `proxies-dns-safe.txt` - IP-only plaintext URIs
- `proxies-dns-safe.json` - IP-only dataset

#### Adapter Formats
- `shadowrocket-dns-safe.txt` - IP-only Shadowrocket
- `surge-dns-safe.conf` - IP-only Surge
- `loon-dns-safe.conf` - IP-only Loon
- `quantumult-dns-safe.conf` - IP-only Quantumult X
- `sip008-dns-safe.json` - IP-only SIP008

#### Specialized Outputs
- `chosen/base64-dns-safe.txt` - IP-only chosen subset
- `singbox-chains-dns-safe.json` - IP-only chains (all types)
- `chains-dns-safe.json` - Alias for singbox-chains-dns-safe.json
- `revived-dns-safe.json` - IP-only revived proxies
- `side_products-dns-safe.zip` - IP-only side products

### 3. DNS-Hardened Outputs (Prefer IP + DoH/DoT/DoQ)

DNS-hardened outputs prefer IPs when available but keep hostnames as fallback. They embed encrypted DNS resolvers (DoH/DoT/DoQ).

#### Primary Formats

## Chain Types Included

All chain outputs (`singbox-chains.json` and variants) include:

### 1. Standard Washed Chains
- **Source**: `washer.wash_batch()` for working proxies
- **Tag Pattern**: `🛡️ Secure-*` or `🛡️⚡ Optimal-*`
- **Topology**: `Client → Proxy → WARP → Internet`
- **Purpose**: Hide proxy IP from destination (unblock Netflix/Google)
- **Tags**: `PROC:WASHED`, `WARP`
- **Included in**: Standard, DNS-Safe, DNS-Hardened

### 2. Revived Chains (WARP)
- **Source**: `washer.wash_failed()` with `use_vwarp=False`
- **Tag Pattern**: `WARP-REVIVE-*` (chain), `WARP-RELAY-*` (relay)
- **Topology**: `Client → Proxy → WARP → Internet`
- **Purpose**: Resurrect failed proxies using WARP
- **Tags**: `REVIVED`, `WARP`, `PROC:REVIVED-WARP`
- **Included in**: Standard, DNS-Safe, DNS-Hardened

### 3. Revived Chains (Vwarp)
- **Source**: `washer.wash_failed()` with `use_vwarp=True`
- **Tag Pattern**: `VWARP-REVIVE-*` (chain), `VWARP-RELAY-*` (relay)
- **Topology**: `Client → Proxy → Vwarp → Internet`
- **Purpose**: Resurrect failed proxies using Vwarp
- **Tags**: `REVIVED`, `VWARP`, `PROC:REVIVED-VWARP`
- **Included in**: Standard, DNS-Safe, DNS-Hardened

### 4. Shielded Chains (Gold)
- **Source**: `washer.shield_batch()` for failed proxies
- **Tag Pattern**: `GOLD-*` (user-facing), `SHIELD-*` (internal)
- **Topology**: `Client → WARP (Clean IP) → Proxy → Internet`
- **Purpose**: Hide proxy IP from censor (ISP) - Copper to Gold transformation
- **Tags**: `SHIELDED`, `GOLD`, `PROC:SHIELDED`
- **Included in**: Standard, DNS-Safe, DNS-Hardened

### 5. Smart Chains
- **Source**: `generate_smart_chains()` for optimized routing
- **Tag Pattern**: Various (Intranet, IPv6, Streamer, etc.)
- **Topology**: Multi-hop optimized paths
- **Purpose**: Optimized routing for specific use cases
- **Tags**: `PROC:SMART-CHAIN`, `SMART:*`
- **Included in**: Standard, DNS-Safe, DNS-Hardened

## Evasion Features Included

All outputs include evasion features by default:

### TLS Fingerprint Rotation (uTLS)
- **Tag**: `EVASION:UTLS`
- **Applied to**: VMess, VLESS, Trojan, Hysteria2, TUIC
- **Fingerprints**: Chrome, Firefox, Safari, iOS (rotated deterministically)

### TLS Fragmentation
- **Tag**: `EVASION:FRAG`
- **Applied to**: All TLS-enabled protocols
- **Settings**: 100-200 byte fragments, 0-10ms sleep

### Multiplexing with Padding
- **Tag**: `EVASION:MUX`
- **Applied to**: VMess, VLESS, Trojan, Shadowsocks
- **Protocol**: HTTP/2 multiplexing (h2mux)

### ALPN Rotation
- **Tag**: `EVASION:ALPN`
- **Applied to**: VMess, VLESS, Trojan
- **Protocols**: h2, http/1.1 (rotated deterministically)

## Usage Recommendations

### For Standard Use
- Use: `singbox.json`, `clash.yaml`, `base64.txt`
- When: Normal network conditions, DNS works fine

### For DNS Blocking
- Use: `*-dns-safe.*` variants
- When: DNS is blocked or unreliable
- Example: `singbox-dns-safe.json`, `base64-dns-safe.txt`

### For DNS Poisoning
- Use: `*-dns-hardened.*` variants
- When: DNS returns fake IPs or is censored
- Example: `singbox-dns-hardened.json`, `clash-dns-hardened.yaml`

### For Severe Censorship
- Use: `singbox-chains.json` (Gold connections)
- When: Direct connections fail, need maximum evasion
- Client: Nekobox or Sing-box only

### For Specific Clients
- **Shadowrocket**: `shadowrocket.txt` or `shadowrocket-dns-safe.txt`
- **Surge**: `surge.conf` or `surge-dns-hardened.conf`
- **Loon**: `loon.conf` or `loon-dns-hardened.conf`
- **Quantumult X**: `quantumult.conf` or `quantumult-dns-hardened.conf`
