# ConfigStream Bot Guide

ConfigStream includes a robust Telegram Bot for users to request proxies and manage subscriptions.

## Features

*   **/stats**: View real-time pipeline statistics (active proxies, last update).
*   **/get <COUNTRY_CODE>**: Get a fresh, working proxy for a specific country (e.g., `/get US`).
*   **/sub**: Get universal subscription links for Clash, Sing-box, etc.

## Deployment Modes

### 1. Stateless Cloudflare Worker (Recommended)
For a "Zero Budget" deployment, use the Cloudflare Worker script located at `tools/bot/worker.js`.

1.  Create a new Worker in Cloudflare Dashboard.
2.  Copy the content of `tools/bot/worker.js`.
3.  Set the `TELEGRAM_BOT_TOKEN` environment variable in Cloudflare.
4.  Set your Webhook URL: `https://api.telegram.org/bot<YOUR_TOKEN>/setWebhook?url=<YOUR_WORKER_URL>/webhook`

### 2. Polling Mode (Local/Server)
If you have a server or want to run it locally:

```bash
# Export your token
export TELEGRAM_BOT_TOKEN="your_token_here"

# Run the bot
python -m configstream.cli bot --token $TELEGRAM_BOT_TOKEN
```

## Architecture

The bot fetches data from the static `metadata.json` and `by_country/*.json` files generated by the main pipeline. This ensures the bot remains stateless and does not require a database connection.
