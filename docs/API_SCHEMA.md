# ConfigStream API Schema Documentation

**Version:** 1.2.0
**Last Updated:** 2025-11-21

This document describes the JSON schema for all output files generated by ConfigStream.

---

## 1. `metadata.json` / `summary.json`

**Location:** `output/metadata.json`, `output/summary.json`

Both files contain identical data and provide summary statistics for the frontend dashboard.

### Schema

```json
{
  "last_updated_utc": "string (ISO 8601 timestamp)",
  "total_proxies": "integer (number of working proxies)",
  "total_working": "integer (same as total_proxies)",
  "total_fetched": "integer (total config lines parsed)",
  "duration_seconds": "float (pipeline runtime in seconds)",
  "protocols": {
    "vmess": "integer",
    "vless": "integer",
    "shadowsocks": "integer",
    "trojan": "integer",
    ...
  },
  "countries": {
    "US": "integer",
    "DE": "integer",
    "JP": "integer",
    ...
  },
  "country_stats": {
    "US": "integer (same as countries)",
    "DE": "integer",
    ...
  },
  "latency_distribution": {
    "fast": "integer (< 100ms)",
    "medium": "integer (100-500ms)",
    "slow": "integer (500-1000ms)",
    "very_slow": "integer (> 1000ms)"
  },
  "protocol_colors": {
    "vmess": "string (hex color for charts)",
    "vless": "string",
    ...
  }
}
```

## 2. `proxies.json`

**Location:** `output/proxies.json`

Contains the full list of all working proxies with detailed metadata.

### Schema (Array of Proxy Objects)

```json
[
  {
    "config": "string (full proxy configuration URI)",
    "protocol": "string (vmess, vless, shadowsocks, etc.)",
    "address": "string (IP or domain)",
    "port": "integer (1-65535)",
    "uuid": "string (user ID/password)",
    "remarks": "string (name/label)",
    "country": "string (2-letter country code)",
    "country_code": "string (same as country)",
    "city": "string (city name)",
    "asn": "string (Autonomous System Number)",
    "isp": "string (Internet Service Provider)",
    "org": "string (organization name)",
    "latency": "float | null (milliseconds)",
    "is_working": "boolean",
    "is_secure": "boolean",
    "security_issues": "object (categorized security issues)",
    "tested_at": "string (ISO 8601 timestamp)",
    "details": "object (protocol-specific settings)",
    "throughput_kbps": "integer | null",
    "dns_over_https_ok": "boolean | null",
    "age_seconds": "integer",
    "stale": "boolean",
    "scores": "object (ranking scores)",
    "resolved_ip": "string | null"
  }
]
```

## 3. Protocol-Specific Files

### `output/by_protocol/{protocol}.json`

Same schema as `proxies.json`, but filtered to only include proxies of that protocol.

**Example Protocols:**
- `vmess.json`
- `vless.json`
- `shadowsocks.json`
- `trojan.json`
- `hysteria2.json`
- `wireguard.json`
- `tuic.json`

---

## 4. Country-Specific Files

### `output/by_country/{COUNTRY_CODE}.json`

Same schema as `proxies.json`, but filtered to only include proxies from that country.

**Example Countries:**
- `US.json`
- `DE.json`
- `JP.json`
- `FR.json`
- `UNK.json` (unknown country)

## 5. Client Configuration Files

### 5.1 `base64.txt` / `vpn_subscription_base64.txt`

**Format:** Base64-encoded list of proxy configuration URIs (one per line)

**Content Before Encoding:**
```
vmess://eyJhZGQiOi...
vless://12345678-1234...
trojan://password@...
```

**Content After Encoding:**
```
dm1lc3M6Ly9leUpoWk...
```

### 5.2 `clash.yaml`

**Format:** Clash YAML configuration

**Schema:**
```yaml
port: 7890
socks-port: 7891
allow-lan: true
mode: Rule
log-level: info
external-controller: 127.0.0.1:9090
proxies:
  - name: "US 01 | VMESS"
    type: vmess
    server: example.com
    port: 443
    uuid: 12345678-1234-1234-1234-123456789abc
    alterId: 0
    cipher: auto
    network: ws
    ws-opts:
      path: /api/v1
      headers:
        Host: example.com
    tls: true
    servername: example.com
proxy-groups:
  - name: "🚀 ConfigStream Auto"
    type: url-test
    url: http://www.gstatic.com/generate_204
    interval: 300
    tolerance: 50
    proxies:
      - "US 01 | VMESS"
      - "DE 02 | VLESS"
  - name: "🌍 Proxy Select"
    type: select
    proxies:
      - "🚀 ConfigStream Auto"
      - "US 01 | VMESS"
rules:
  - "MATCH,🚀 ConfigStream Auto"
```

## 6. Data Types & Validation

### Port
- **Type:** Integer
- **Range:** 1-65535
- **Validation:** Must be valid port number, dangerous ports (e.g., 22, 23, 3389) are filtered

### Country Code
- **Type:** String
- **Format:** 2-letter ISO 3166-1 alpha-2 code
- **Example:** `"US"`, `"DE"`, `"JP"`, `"UNK"` (unknown)

### Timestamp
- **Type:** String
- **Format:** ISO 8601 with UTC timezone
- **Example:** `"2025-11-21T12:34:56.789Z"`

### Latency
- **Type:** Float | null
- **Unit:** Milliseconds
- **Range:** > 0
- **Null:** Indicates proxy not tested or test failed

### Protocol
- **Type:** String
- **Enum:** vmess, vless, shadowsocks, ss2022, trojan, hysteria, hysteria2, tuic, wireguard, xray, snell, brook, juicity, ssh, openvpn, http, https, socks, socks4, socks5, naive

## 7. Versioning & Compatibility

### Backward Compatibility

ConfigStream maintains backward compatibility for all JSON schemas. New fields may be added but existing fields will not be removed or changed in meaning.

### Version Detection

Check the `last_updated_utc` field in `metadata.json` to determine data freshness.

---

## 8. Error Handling

### Empty Results

If no proxies are found, `proxies.json` will contain an empty array:
```json
[]
```

And `metadata.json` will have zero counts:
```json
{
  "last_updated_utc": "2025-11-21T12:34:56.789Z",
  "total_proxies": 0,
  "total_working": 0,
  ...
}
```

### Partial Data

Some proxy objects may have null values for optional fields:
- `latency`: null if test failed
- `city`: null if GeoIP lookup failed
- `resolved_ip`: null if DNS resolution not performed

## 9. Rate Limiting & Caching

### GitHub Pages Serving

- **Cache-Control:** Files are served with cache-busting query parameters (e.g., `?t=1732201234`)
- **Update Frequency:** Every 6 hours (00:00, 06:00, 12:00, 18:00 UTC)
- **Recommendation:** Frontend should cache for 3 hours maximum

### API Usage Guidelines

1. Use `metadata.json` to check `last_updated_utc` before fetching `proxies.json`
2. Cache `proxies.json` locally for at least 30 minutes
3. Use protocol/country-specific files to reduce bandwidth if filtering

## 10. Security Considerations

### Data Integrity

- All JSON files are generated atomically with fsync to prevent corruption
- Files are served over HTTPS via GitHub Pages

### Privacy

- No personally identifiable information (PII) is collected or stored
- Source URLs are not exposed in output files
- Proxy configurations are publicly available from source repositories

### Validation

All proxy objects have been:
1. Parsed and validated for correct format
2. Security tested for dangerous ports, suspicious domains, honeypots
3. Live tested for actual connectivity
4. Geolocated and enriched with metadata
