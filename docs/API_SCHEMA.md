# API Schema Documentation

This document defines the JSON schemas for the public output files generated by ConfigStream.

## `metadata.json`

Contains high-level statistics and metadata about the pipeline run.

```json
{
  "last_updated_utc": "2023-10-27T10:00:00+00:00", // ISO 8601
  "total_proxies": 1250,                           // Integer
  "total_working": 850,                            // Integer
  "total_fetched": 15000,                          // Integer
  "duration_seconds": 45.5,                        // Float
  "protocols": {                                   // Counts by protocol
    "vmess": 300,
    "vless": 200,
    "shadowsocks": 150,
    ...
  },
  "countries": {                                   // Counts by Country Code
    "US": 120,
    "JP": 80,
    ...
  },
  "country_stats": {                               // Same as countries (redundant for backward compat)
    "US": 120,
    ...
  },
  "latency_distribution": {                        // Latency buckets
    "fast": 100,      // < 100ms
    "medium": 300,    // 100-500ms
    "slow": 400,      // 500-1000ms
    "very_slow": 50   // > 1000ms or timeout
  },
  "protocol_colors": {                             // Hex colors for UI
    "vmess": "#FF6B6B",
    ...
  }
}
```

## `proxies.json` (and `by_protocol/*.json`, `by_country/*.json`)

A list of proxy objects.

```json
[
  {
    "protocol": "vmess",             // String: vmess, vless, shadowsocks, etc.
    "username": "uuid-here",         // String (Optional): UUID or user
    "password": "pass",              // String (Optional)
    "server": "1.2.3.4",             // String: IP or Hostname
    "port": 443,                     // Integer
    "country": "US",                 // String: Country Name (e.g. "United States")
    "country_code": "US",            // String: 2-letter ISO code
    "city": "New York",              // String
    "latency": 120,                  // Integer: Latency in ms
    "is_working": true,              // Boolean
    "details": {                     // Object: Protocol-specific details
      "type": "ws",
      "host": "example.com",
      "path": "/path",
      "tls": "tls",
      "sni": "example.com",
      "fp": "chrome",
      "alpn": ["h2", "http/1.1"]
    },
    "tags": ["official", "fast"],    // Array[String]
    "config": "vmess://..."          // String: Original or regenerated config URI
  }
]
```
