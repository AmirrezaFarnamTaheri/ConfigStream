How This Works

No internet? Start with a local proxy (Psiphon, Lantern, V2RayN) as Layer 1. Then stack WARP or your destination proxy on top.

Example 3-layer chain: You → SOCKS5 (local Psiphon) → WARP (clean IP) → VLESS (destination) → Internet

To run: Save the config, then: sing-box run -c config.json and set proxy to socks5://127.0.0.1:2080

Find clean IPs offline: python lab-scanner.py --scan-ips

Find local proxies: python lab-scanner.py --scan-proxies

Full diagnostic: python lab-scanner.py
