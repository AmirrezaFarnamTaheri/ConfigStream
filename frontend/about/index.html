About ConfigStream

Building the Resilient Internet Layer.

Our Mission

ConfigStream is an automated, open-source intelligence platform designed to aggregate, test, and distribute high-performance proxy configurations. In an era of increasing internet censorship and fragmentation, we provide the tools to maintain connectivity and bypass restrictions securely.

Core Architecture

The platform operates on a "Zero Budget" philosophy, leveraging GitHub Actions for compute and GitHub Pages for distribution. Our hybrid engine combines the flexibility of Python with the raw performance of Go.

Hybrid Engine

Python orchestrates the logic, while a custom Go binary handles high-concurrency network scanning and testing.

The Washer (Proxy Reviver)

Our intelligent "Washer" module wraps flagged or dirty proxies in Cloudflare WARP tunnels, reviving them for safe use.

Smart Routing

Topology-aware chaining connects domestic relays to foreign exit nodes, bypassing deep packet inspection (DPI).

Active Scanner

A built-in Go scanner actively discovers fresh, low-latency Cloudflare endpoints to ensure maximum performance.

Security & Intelligence

ConfigStream incorporates multi-layered security validation to ensure proxy safety and reliability. Our intelligence pipeline filters out malicious nodes through comprehensive threat detection.

FireHol Blocklist Integration

Real-time validation against known malicious IP addresses from FireHol's community-maintained blocklists.

Honeypot Detection

Advanced heuristics identify and filter out honeypot traps designed to monitor user activity.

Configuration Validation

Strict parsing and validation ensures all configs are well-formed, non-malicious, and standards-compliant.

Dynamic Resharding

Intelligent load balancing based on actual fetch and test times ensures optimal pipeline performance.
