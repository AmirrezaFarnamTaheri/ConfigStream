Five steps to a working connection:

  1. Pick a format — choose the subscription that matches your VPN client (Sing-box, Clash, V2Ray, Shadowrocket, etc.)
  2. Copy the link — click the copy button next to your chosen format
  3. Import — paste the link into your client's subscription manager
  4. Update — refresh the subscription to fetch the latest proxies
  5. Connect — select any proxy from the list

Subscriptions auto-update on a schedule, so you always have fresh proxies.

ConfigStream runs an automated, zero-cost pipeline on GitHub Actions:

  • Collection: Every ... hours, proxies are aggregated from over ... public sources worldwide
  • Deduplication: Advanced filtering removes duplicates and invalid entries
  • Verification: A hybrid Go + Python engine tests each proxy for connectivity and speed
  • Security: Automated checks filter out honeypots, malware hosts, and unsafe nodes
  • Ranking: Proxies are scored by latency, reliability, and protocol intelligence
  • Publishing: Configs are generated for all major VPN clients and three DNS profiles
